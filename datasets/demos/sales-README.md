# Sales fixtures

`merging/sales-jan-2026.csv`, `merging/sales-feb-2026.csv`, `merging/sales-mar-2026.csv` and
`10-time-series/sales-feb-2026.csv` are invented order logs for teaching: one row per order, with the
order time (`Date`), a fictional `Company`, a `Product` category and the number of `Units`.
They are not real sales. The timestamps are local times without a time zone.
